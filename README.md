# Jarurat Care – Assignment Project

## Overview
A responsive web app for an NGO-style cancer care support initiative. It highlights services, live impact stats, a multi‑step support request form, and an embedded AI helper for guidance.

## Tech Stack
- React + TypeScript (Vite)
- Tailwind CSS
- Framer Motion (animations)
- Supabase (data storage for impact stats and support requests)

## AI Idea
“Sahayak” is a lightweight, on‑page AI assistant that answers common questions, explains services, and nudges users to submit support requests when needed.

## NGO Use‑Case
Designed for cancer care NGOs to:
- Showcase services and impact
- Collect patient support requests in a structured flow
- Provide quick guidance via an AI assistant
